# Tibo 全部新动态的中文邮件

本分支将 Tibo（`@thsottiaux`）自己发布的全部新帖子和回复发送为中文邮件，不再只匹配 reset。保留英文原文、原帖链接和北京时间；图片以远程 HTTPS 图片引用展示，不分析或翻译图片中的文字。转发他人的内容仍按上游来源规则排除。

## GitHub Actions Secrets

在仓库 Settings → Secrets and variables → Actions 中填写：

| 名称 | 内容 |
| --- | --- |
| `SMTP_USER` | Gmail 发件邮箱 |
| `SMTP_PASSWORD` | Gmail 应用专用密码，不能使用 Google 登录密码 |
| `EMAIL_FROM` | 同一个 Gmail 发件邮箱 |
| `EMAIL_TO` | 目标收件邮箱 |

邮箱地址和密码都保存在 Secrets 中，不写入公开源码。SMTP 默认使用 `smtp.gmail.com:465` 的 TLS 连接。翻译仅向 Google Translate 网页翻译接口传输公开帖子的正文，不传输邮箱凭据。该翻译入口和 FxEmbed 均为第三方依赖；失败会保留待发送消息，在下次运行重试。

## 运行与验证

运行工作流“Tibo 中文邮件通知”，勾选“发送一封最新真实帖子的中文测试邮件”，可用最新已抓取的真实帖子验证翻译和发信链路。首次监测只建立最新游标，避免一次性补发历史消息。

默认每五分钟检查一次。GitHub 排队、数据源缓存和邮件投递均可能造成额外延迟，不能保证秒级或绝对不漏。读取和发送断点持久化到独立 `monitor-state` 分支；每个目标成功发送后保存状态。SMTP 在服务端已接受但客户端断线、或服务端接受后 GitHub 状态未保存时，重试可能造成重复邮件；固定 Message-ID 有助于邮箱归并，但不能保证服务端幂等。
